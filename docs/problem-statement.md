# Problem Statement

Carbon-aware delivery work needs clear boundaries between implemented behavior, planned experiments, and unsupported impact claims.

CarbonOps currently explores this area as a pre-alpha reference toolkit. The current repository is useful for documenting:

- CLI shape.
- Placeholder scheduling behavior.
- Measurement-boundary questions.
- Public-safe examples.
- Architecture decisions about scope and maturity.

CarbonOps does not currently prove adoption, operational use, commercial impact, verified emissions reduction, or external recognition.
