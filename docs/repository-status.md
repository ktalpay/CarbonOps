# Repository Status

## Current Status

CarbonOps is pre-alpha. Under active hardening.

## Implemented Now

Currently implemented:

- Python package skeleton.
- Typer-based CLI.
- `version` command.
- Placeholder `schedule` command.
- Basic CLI tests for current behavior.
- README reframed for pre-alpha scope.
- Initial documentation baseline.

## Not Implemented Yet

Not implemented yet:

- Real carbon-intensity adapters.
- Real scheduling engine.
- CO2e reporting methodology.
- Demo workflow.
- ADR baseline.
- Reviewed CI decision.
- Screenshot evidence package.

## Known Limitations

- The scheduler is placeholder behavior.
- Measurement assumptions are not complete.
- The repository does not prove public adoption, production usage, commercial impact, verified emissions reduction, or external recognition.
- Documentation should not be treated as proof of implementation.

## Review Status

The repository is becoming easier to inspect, but it still needs ADRs, demo or example workflow decisions, CI review, screenshots, and evidence review.

Not pin-ready yet.
