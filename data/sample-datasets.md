# Sample Datasets

No real dataset is included in the current pre-alpha baseline.

Future sample data should be synthetic or use a clearly documented public data source. Any future dataset example should document:

- Source and license.
- Region coverage.
- Time-window assumptions.
- Units.
- Missing or stale data behavior.
- Whether values are synthetic, estimated, or measured.

Do not add private data, customer data, internal endpoints, credentials, or unsupported carbon-impact claims.
